# חבילת אווטרים — Zemingo Halloween

סט ראשון לשילוב: 8 דמויות PNG נפרדות, 1254×1254 פיקסלים כל אחת. נוצרו במהלך העבודה על התחרות. הסגנון איורי פשוט עם הצללה עדינה ורקע פחם אטום; אלה אינם SVG או קבצים שקופים. אין שינוי בסגנון דמות ההירו הנפרדת.

הדמויות: פרנקנשטיין, ערפד, ראש דלעת, שלד, מכשפה, מומיה, רוח רפאים ואיש זאב. מדובר בסט עיצובי מוצע לשימוש, לא בשינוי כללי התחרות.

## הוראות ל־Claude Code

1. העתק את שמונת קובצי PNG לתיקיית public/avatars של הפרויקט, או לנתיב הסטטי המקביל.
2. טען את catalog.json כמיפוי מזהים ותוויות. publicPath מציין את כתובת התמונה באפליקציה; file הוא הקובץ המקומי בחבילה.
3. השאר את המזהים ללא שינוי. בצע upsert של פרטי הקטלוג, לא מחיקה ויצירה מחדש, כדי לשמור בחירות קיימות. הרשמה שומרת avatarId בלבד.
4. הצג את התמונות ביחס 1:1 עם border-radius:50%, object-fit:cover ו־object-position:center. אל תוסיף zoom או חיתוך נוסף. הכובע והאוזניים ייבדקו בתצוגה העגולה בפועל.
5. גריד 4×2 כאשר יש מקום; תווית עברית מתחת לכל דמות. ללא בחירה אוטומטית. radio group נגיש, טבעת פוקוס נפרדת ממסגרת הבחירה וסימן ✓ שאינו מסתיר את הפנים.
6. בחירה מוצגת בגודל 64–96px; לצד יוצר תוצר 32–40px. שמות נגישים מחוץ לתמונות; אין להטביע טקסט בתוך הקובץ. כשהתווית כבר נותנת שם לפקד, alt ריק מונע כפילות.
7. כשל טעינת תמונה מציג placeholder עם אותה תווית ומזהה. אין לחסום הרשמה בגלל טעינת תמונה ואין לשנות בחירה שנשמרה.
8. האווטרים סטטיים. אפשר מעבר מסגרת קצר ב־hover/focus, בלי לולאות אנימציה בגריד. כמה עובדים יכולים לבחור אותה דמות לפי ברירת המחדל המתועדת.
9. לפני פרסום השתמש במנגנון אופטימיזציית התמונות של הפרויקט עם גדלים תואמים לתצוגה; אין צורך לשלוח את כל קובצי המקור המלאים לרשימת אווטרים קטנה. שמור את קובצי המקור ואל תשנה מזהים בשל שינוי פורמט.

## בדיקות

נבדקו קבצי המקור: שמונה קבצים נפרדים, מידות אחידות, רקע אטום ומיפוי קטלוג לכל תמונה. עדיין יש לבדוק בממשק האמיתי: מובייל, מסכה עגולה, מקלדת, קריאות ב־32px, שמירה בשרת ובחירות קיימות. אין כאן אפליקציה או טענה שבדיקות UI כבר בוצעו.

## פרומפט המשך

קרא את הוראות האווטרים ואת catalog.json. החלף את האווטרים הזמניים בשמונת הקבצים המצורפים, תוך שמירה על המזהים והבחירות הקיימות. אל תשנה את תהליך ההרשמה או את כללי התחרות. בדוק בחירה במקלדת, תצוגה עגולה במובייל וטעינת fallback.
